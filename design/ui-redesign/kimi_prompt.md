# 请你评审一个大学书院问答机器人的界面改版

## 背景
澳门大学張崑崙书院（CKLC）的学生端问答页，用户是会到书院办公室问事的本科生（18-22 岁，繁体中文为主，也用简体/英文）。
页面功能：输入问题 → 后端 FastAPI 返回答案 + 依据条目 → 用户可点开看原文、点赞/点踩。
技术约束很硬：HTML 结构已被 JS 绑死（#log 里由脚本动态生成 .msg/.bubble/.cite/.fb），我只能改 CSS 和顶栏结构，不能改 JS 行为。

## 旧版的问题（用户原话）
"太土，没有高级感。" 具体是：整条 header 铺满深红、彩色气泡配 12px 圆角、字号只有一个层级、padding 24px 贴边、圆角半径混用、没有任何细节层次。

## 新版方案（已实现并跑通真实数据）
- 背景：暖白底 + 两处极淡的径向渐变（左上酒红 13%、右下暖橙 15%）+ 3% 透明度的 22px 网格纹理，只在页面上部可见（mask 渐隐）
- 顶栏：毛玻璃（backdrop-filter blur 18px），两行。第一行 头像 + 标题（14px，单行省略）+ 语言切换（繁/简/EN 药丸）；第二行 学号药丸 + 「測試版 · 資料未審核 · AI 生成 · 僅供參考」小字（9px 等宽）
- 免责条：白 46% 底 + 2px 酒红左边线 + 11.5px 灰字，正文里的粗体改成墨色而不是红色
- 消息：AI 气泡是白 72% 玻璃 + 1px 白边 + 内阴影，左下角 4px 小圆角；用户气泡是酒红 11% 底 + 24% 边框，右下角小圆角，右对齐，头像位置放一个「我」
- 依据：<details> 折叠，标题行是 10px 等宽酒红字带 ▸，展开后是更浅的玻璃卡片，原文用 2px 左边线引用
- 反馈：11px 药丸按钮
- 底部：固定，向上渐隐到透明并带 blur；快捷问题是横向滚动的药丸（右侧 mask 渐隐）；输入框是 999px 药丸 + 玻璃；发送按钮是深红渐变圆角
- 学号弹窗：底部抽屉式，20px 上圆角

## 现在请你判断的问题（每条给 2-4 句结论 + 一个能直接落到 CSS 的改法）
1. 「高级感」这件事，这套做法是走对了，还是只是把土的东西做得更浅？如果只允许再改三处，你改哪三处？
2. 这是给学生办事用的页面，不是作品集。玻璃拟态 / 渐变背景在这类场景里是加分还是减分？会不会让「可信」变弱？
3. 免责提示：现在顶栏小字、免责条、欢迎语三处都在说「AI 生成，仅供参考」。我不能删法务文本，但可以让视觉更安静。你会怎么排？
4. 移动端 420px 宽，顶栏两行（标题 + 学号 + 两个状态 + 语言）是否信息过载？有更好的组织方式吗？
5. 用户气泡用酒红 11% 底，会不会和暖粉背景太接近、对比不足？给一个具体的颜色值建议。
6. 还有什么我没问到但你觉得必须改的？

不要长篇大论，不要客套，直接给结论和数字。
