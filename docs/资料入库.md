# 资料入库：把文件变成能查的条目

## 一条命令

```bash
mkdir inbox
# 把 PDF / md / txt 丢进 inbox
.venv\Scripts\python.exe scripts\ingest_docs.py inbox --version AY2026-2027
```

先预览会切多少段：

```bash
.venv\Scripts\python.exe scripts\ingest_docs.py inbox --dry-run
```

## 它怎么切

| 文件长什么样 | 切法 | anchor |
|---|---|---|
| 有 `1.1`、`2.4.1` 这类条款号 | 按条款切 | `1.1` |
| 海报、通知、FAQ（没有编号） | 按空行切，每段 ≤ 900 字 | `p01`、`p02` |
| 扫描件（没有文字层） | 跳过，会提示 | — |

同一 `source + version` 再导一次会**先删后插**，不会重复。所以文件改版了，直接用新版本号重跑。

## 导进去之后

- 审核页的「规章原文（自动匹配）」会开始出现这些新段落
- `get_clause` 能按 anchor 取到
- 崑崑回答问题时，检索会把它们当作依据候选

**注意**：`chunk` 只是原文仓库。要不要让崑崑直接引用，取决于问答条目有没有绑到它——绑定的活还是在审核页做。

## 现在缺哪些文件

按“学生最常问”的顺序：

1. **收费与押金** —— 洗衣、打印、冷气、房卡补办、押金退还（ISW 财务口径）
2. **门禁与访客** —— 几点关门、访客登记、过夜申请
3. **饭堂** —— 开放时间、餐标、充值方式
4. **WiFi** —— 连哪个 SSID、怎么认证、掉线找谁
5. **快递** —— 收件点在哪、代收规则
6. **打印** —— 打印机位置、收费标准、充值

拿到什么格式都行：PDF、Word、甚至微信里的截图（截图我得先 OCR）。丢进 `inbox/` 或直接发我。

## 已知坑

- 扫描件（图片型 PDF）没有文字层，`ingest_docs.py` 会跳过并提示；要 OCR 先转文字
- 学年口径：`--version` 写 `AY2026-2027` 这类，别用「2026版」这种含糊写法
- 中英混排的文件会被切成中英各段，这是有意的（检索按语言分别命中）
