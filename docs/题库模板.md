# 题库模板

Excel 两列即可，第一行是表头，从第二行开始每条一行。

| 问题 | 答案 |
|---|---|
| 健身房开放时间是什么时候？ | 每天 7:00-23:00，在 G024、G026、G027 三间。 |
| 宿舍可以养宠物吗？ | 不行。除辅助犬外，住宿生和访客都不能把宠物带进书院。 |

## 写法建议

**问题按学生的说法写，不要按规章的措辞写。** 学生问「房卡丢了怎么办」，不会问「门禁卡遗失补办流程」。可以一条答案配多个问法，各占一行。

**答案先给结论，再补条件。** 第一句就要能直接用：几点、在哪、能不能、要不要申请。后面再放例外情况。

**不要把多条不相关的规定塞进一个答案。** 一条一个断言，将来改其中一条不会连累别的。

## 分档（可选列）

如果加第三列 `ttl`，取值：

- `A` 长期稳定（房型、地址、办公室位置）——直接答
- `B` 每年会变（住宿费、学期安排、申请时间）——答案前会加学年前缀
- `C` 实时（活动、临时通知）——只给链接，不转述

不填默认 `A`。

## 导入

```bash
python scripts/build_kb.py 你的题库.xlsx
```

跑完看整理报告里的警告：没来源的、答案过短的、疑似重复的，逐条处理再进审批端。
